A single-line out-of-office auto-reply for the make.fun bounty "The Funniest Out-of-Office": a hiker heads for the one spot with no signal — not to escape email, but to find out which colleague emails first. The program writes exactly that one line — 91 characters, no trailing newline — to `/output/entry.txt`.

## Run

```sh
node main.ts
```
